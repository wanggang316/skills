# tauri-svelte

A Claude Code skill that scaffolds and extends Tauri v2 + Svelte 5 desktop applications — from project bootstrap to production-ready features.

## Quick Start

**Option 1 — CLI**

```bash
npx skills https://github.com/wanggang316/skills --skill tauri-svelte
```

**Option 2 — YouSkill**

Browse and install via [youskill.cc](https://youskill.cc).

## Capabilities

| Capability | Description |
|---|---|
| **Bootstrap** | Scaffold a new Tauri v2 + Svelte 5 desktop app from a production-ready template |
| **Icon** | Replace the default app icon with a custom 1024×1024 PNG across all platforms |
| **Tray** | Add a system tray / menu bar icon with a context menu and click handlers |
| **Updater** | Configure the built-in auto-updater for over-the-air app updates |
| **Markdown** | Add rich Markdown rendering with syntax highlighting and code copy support |
