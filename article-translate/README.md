# article-translate

A skill for translating web articles, blog posts, essays, and technical posts from a URL into polished Chinese Markdown files.

## Quick Start

**Option 1 — CLI**

```bash
npx skills https://github.com/wanggang316/skills --skill article-translate
```

**Option 2 — Ask your Agent**

```text
Install the `article-translate` skill from https://github.com/wanggang316/skills.git
```

**Option 3 — YouSkill**

Browse and install via [youskill.cc](https://youskill.cc).

## Capabilities

| Capability | Description |
|---|---|
| **Translate** | Translate a high-quality article from a URL into polished Chinese Markdown files |

## Usage

Use this skill when the user explicitly asks to translate, for example:

```text
翻译这篇文章：https://openai.com/index/harness-engineering/
```

```text
把这个网页翻成中文：https://martinfowler.com/articles/agentic-ai.html
```

```text
translate this post: https://example.com/post
```

Do not use this skill for a bare URL without translation intent.
