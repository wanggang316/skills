# build-with-ai

用 AI 协作构建产品的标准流程。

## 概述

Build with AI 是一个人机协作构建产品的流程框架，帮助：
- 个人开发者快速构建产品
- 用 AI 协作方式提高效率
- 建立标准化的产品开发流程

## 流程

```
第一步：想法 & 草图 → 第二步：产品文档 → 第三步：开发
```

## 使用

当用户想要构建新产品时，引导用户按照流程执行：

1. **第一步** - 提出想法，画出草图
2. **第二步** - 完善产品文档
3. **第三步** - AI Coding 开发
