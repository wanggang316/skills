# build-with-ai

用 AI 协作构建产品的标准流程。

## 概述

Build with AI 是一个人机协作构建产品的流程框架，帮助：
- 个人开发者快速构建产品
- 用 AI 协作方式提高效率
- 建立标准化的产品开发流程

## 流程

```
定义 → 设计 → 开发
```

## 使用

当用户想要构建新产品时，引导用户按照流程执行：

1. **定义** - 确认产品名称，创建项目目录，完善需求、问题、用户
2. **设计** - 完善核心流程、功能、页面、技术、数据、接口
3. **开发** - AI Coding 开发
