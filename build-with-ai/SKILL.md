# Build with AI

用 AI 协作构建产品的标准流程。

## 什么是 Build with AI

这是一个人机协作构建产品的流程框架：
- **人类** 出想法，做决策
- **AI** 执行建议、协助文档、代码开发

## 什么时候使用

当用户说以下话术时：
- "想要做一个 xx 产品"
- "我有一个什么想法"
- "想做个小工具"
- "想做个 App"
- "新建项目"
- "开始做 xx"
- "产品开发"
- "build a product"

## 流程概览

```
立项 → 想法 & 草图 → 产品文档 → 开发
```

| 步骤 | 执行者 | 输出 |
|------|--------|------|
| 0. 立项 | 人类 + AI | 项目目录、立项文档 |
| 1. 想法 & 草图 | 人类 | 草图、产品想法、功能、人群 |
| 2. 产品文档 | 人类 + AI 协作 | 核心流程、功能列表、页面结构、数据设计 |
| 3. 开发 | AI Coding | 代码、测试、部署 |

## 详细流程

### 第 0 步：立项

**触发话术**：
- "想要做一个 xx 产品"
- "我有一个什么想法"
- "想做个小工具"
- "想做个 App"
- "新建项目"
- "开始做 xx"

**AI 行动**：
1. 询问用户是否创建新项目
2. 确认产品名称
3. 询问产品文档目录（如果之前没说过）
4. 在产品文档目录下创建项目目录
5. 创建立项文档

**输出**：
- 项目目录
- 立项文档

**模板位置**：[assets/立项模板.md](assets/立项模板.md)

---

### 第一步：想法 & 草图

**执行者**：人类

**要做的事情**：
1. 提出想法 - 描述问题和初步想法
2. 画草图 - 用 Excalidraw 或示意图
3. 明确要素 - 产品定位、主要功能、面向人群

**输出**：
- 草图文件（.md 格式，Excalidraw）
- 产品定位
- 主要功能
- 面向人群

**模板位置**：[assets/立项模板.md](assets/立项模板.md)

---

### 第二步：产品文档

**执行者**：人类 + AI 协作

**要做的事情**：
1. 完善核心流程
2. 详细功能描述
3. 页面结构
4. 数据设计
5. 技术选型

**输出**：
- 核心流程文档
- 功能列表
- 页面结构
- 数据设计
- 技术选型

**模板位置**：
- [assets/核心流程模板.md](assets/核心流程模板.md)
- [assets/功能列表模板.md](assets/功能列表模板.md)
- [assets/页面结构模板.md](assets/页面结构模板.md)
- [assets/数据设计模板.md](assets/数据设计模板.md)
- [assets/技术选型模板.md](assets/技术选型模板.md)

---

### 第三步：开发

**执行者**：AI Coding（人类监督）

**要做的事情**：
1. 技术选型确认
2. 项目初始化
3. 代码实现
4. 测试
5. 部署

**输出**：
- 可运行的产品代码

---

## 核心原则

1. **先想清楚再做** - 不着急写代码，先把需求盘明白
2. **文档驱动开发** - 没有文档不开发
3. **AI 协作** - 人类出想法，AI 执行和建议
4. **迭代优化** - 随时根据反馈调整

## 使用方法

1. 用户表达想做产品时，引导进入"立项"环节
2. 确认产品名称和文档目录
3. 创建项目目录和立项文档
4. 按照流程逐步执行
5. 每个步骤使用对应的模板
