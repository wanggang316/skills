# 第二步：设计

## 目标

把需求写清楚，形成可执行的文档。

## 执行者

人类 + AI 协作

## 输出

- 核心流程文档
- 功能列表
- 页面设计
- 技术选型
- 数据结构设计
- 接口设计

## 步骤

### 2.1 完善核心流程

定义完整的业务流程：
- 第一步：做什么
- 第二步：做什么
- 第三步：做什么
- 第四步：做什么

### 2.2 详细功能描述

每个功能包含：
- 功能名称
- 功能描述
- 输入/输出
- 业务流程

### 2.3 页面设计

- 页面结构
- 菜单设计
- 交互流程

### 2.4 技术选型

确认：
- 前端技术
- 后端技术
- 存储方案
- 第三方服务

### 2.5 数据结构设计

- 主要数据表
- 字段设计
- 关系

### 2.6 接口设计

- API 接口列表
- 请求/响应格式

## 产出模板

```markdown
# [产品名称] 产品设计

## 核心流程
1. [步骤 1]
2. [步骤 2]
3. [步骤 3]
4. [步骤 4]

## 功能列表
### 功能 1
- 描述：...
- 输入：...
- 输出：...

## 页面设计
### 页面 1
- 功能：...
- 交互：...

## 技术选型
- 前端：...
- 后端：...
- 存储：...

## 数据设计
### 表 1
- 字段：...
- 关系：...

## 接口设计
### API 1
- 请求：...
- 响应：...
```
