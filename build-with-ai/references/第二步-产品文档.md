# 第二步：产品文档

## 目标

把需求写清楚，形成可执行的文档。

## 执行者

人类 + AI 协作

## 输出

- 核心流程文档
- 功能列表
- 页面结构
- 数据设计
- 技术选型

## 步骤

### 2.1 完善核心流程

定义完整的业务流程：
- 第一步：做什么
- 第二步：做什么
- 第三步：做什么
- 第四步：做什么

### 2.2 详细功能描述

每个功能包含：
- 功能名称
- 功能描述
- 输入/输出
- 业务流程

### 2.3 页面结构

管理系统：
- 菜单结构
- 每个页面的功能
- 页面交互流程

### 2.4 数据设计

数据库思路：
- 主要数据表
- 字段设计
- 关系

### 2.5 技术选型

确认：
- 前端技术
- 后端技术
- 存储方案
- 第三方服务

## 产出模板

```markdown
# [产品名称] 产品设计

## 核心流程
1. [步骤 1]
2. [步骤 2]
3. [步骤 3]
4. [步骤 4]

## 功能列表
### 功能 1
- 描述：...
- 输入：...
- 输出：...

### 功能 2
- 描述：...
- 输入：...
- 输出：...

## 页面结构
### 页面 1
- 功能：...
- 交互：...

### 页面 2
- 功能：...
- 交互：...

## 数据设计
### 表 1
- 字段：...
- 关系：...

## 技术选型
- 前端：...
- 后端：...
- 存储：...
```

## 检查清单

- [ ] 核心流程完整
- [ ] 功能描述清晰
- [ ] 页面结构明确
- [ ] 数据设计合理
- [ ] 技术选型确认
