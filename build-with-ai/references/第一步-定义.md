# 第一步：定义

## 目标

明确产品定位，形成初步概念，创建项目基础。

## 执行者

人类 + AI 协作

## 输出

- 项目目录
- 产品定义文档
- 产品草图（可选）

## 步骤

### 1.1 立项

AI 询问用户：
1. 是否创建新项目
2. 产品名称
3. 产品文档目录（如果之前没说过）

创建项目目录结构：
```
{产品文档目录}/
└── {产品名称}/
    ├── 01-产品定义/
    ├── 02-产品设计/
    └── 03-开发/
```

### 1.2 需求描述

人类描述：
- 解决什么问题
- 初步的产品想法
- 为什么会做这个

### 1.3 目标用户

明确：
- 谁会用这个产品
- 目标用户群体

### 1.4 产品草图（可选）

用 Excalidraw 或示意图画出：
- 系统架构
- 核心流程
- 关键模块

## 产出模板

```markdown
# [产品名称] 产品定义

## 需求描述
[描述用户想要做什么]

## 解决什么问题
[目标用户遇到什么问题]

## 目标用户
[谁会用这个产品]

## 产品草图
[可选：系统架构图、核心流程图]
```

## 检查清单

- [ ] 项目目录已创建
- [ ] 需求描述清晰
- [ ] 目标用户明确
- [ ] 产品草图（可选）
