# 第一步：立项 & 想法

## 目标

明确「做什么」，形成初步概念，创建项目基础。

## 执行者

人类 + AI 协作

## 输出

- 项目目录
- 立项文档（含产品定位、主要功能、面向人群）
- 草图文件（.md 格式，Excalidraw）

## 步骤

### 1.1 立项

AI 询问用户：
1. 是否创建新项目
2. 产品名称
3. 产品文档目录（如果之前没说过）

创建项目目录结构：
```
{产品文档目录}/
└── {产品名称}/
    ├── 立项.md
    ├── 草图.md
    ├── 01-产品/
    ├── 02-技术/
    ├── 03-设计/
    └── 04-开发/
```

### 1.2 提出想法

人类描述：
- 解决什么问题
- 初步的产品想法
- 为什么会做这个

### 1.3 画草图

用 Excalidraw 或示意图画出：
- 系统架构
- 核心流程
- 关键模块

### 1.4 明确要素

明确：
- **产品定位** - 做什么产品，解决什么问题
- **主要功能** - 核心功能有哪些
- **面向人群** - 谁会用这个产品

## 产出模板

```markdown
# [产品名称]

## 产品定位
[一句话描述产品]

## 核心想法
[详细描述产品想法和解决的问题]

## 面向人群
[目标用户群体]

## 主要功能
- 功能 1
- 功能 2
- 功能 3
```

## 检查清单

- [ ] 项目目录已创建
- [ ] 产品定位清晰
- [ ] 核心功能明确
- [ ] 目标人群确定
- [ ] 有草图或架构图
