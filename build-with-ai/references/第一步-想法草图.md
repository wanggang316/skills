# 第一步：想法 & 草图

## 目标

明确「做什么」，形成初步概念。

## 执行者

人类（Gump）

## 输出

- 草图文件（.md 格式，Excalidraw）
- 产品定位
- 主要功能
- 面向人群

## 步骤

### 1.1 提出想法

人类描述：
- 解决什么问题
- 初步的产品想法
- 为什么会做这个

### 1.2 画草图

用 Excalidraw 或示意图画出：
- 系统架构
- 核心流程
- 关键模块

### 1.3 明确要素

明确：
- **产品定位** - 做什么产品，解决什么问题
- **主要功能** - 核心功能有哪些
- **面向人群** - 谁会用这个产品

## 产出模板

```
# [产品名称]

## 产品定位
[一句话描述产品]

## 核心想法
[详细描述产品想法和解决的问题]

## 面向人群
[目标用户群体]

## 主要功能
- 功能 1
- 功能 2
- 功能 3
```

## 检查清单

- [ ] 产品定位清晰
- [ ] 核心功能明确
- [ ] 目标人群确定
- [ ] 有草图或架构图
